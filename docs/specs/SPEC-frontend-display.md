# 前端展示逻辑 Spec

> 固化日期: 2026-07-09
> 版本: v1.0

---

## 一、核心原则

1. **默认中文显示**：所有标题、摘要、正文在前端必须显示为中文
2. **保留原文可查**：非中文信源的原文正文保留，用户可切换查看
3. **微信版权保护**：微信公众号正文不显示，引导用户点击原文链接阅读

---

## 二、事件卡片展示逻辑

### 2.1 标题

| 条件 | 显示内容 |
|------|----------|
| 所有事件 | `titleCn`（已由 AI 翻译为中文字段） |

### 2.2 摘要

| 条件 | 显示内容 |
|------|----------|
| 所有事件 | `summaryCn`（AI 生成的中文摘要 150-250 字） |

### 2.3 正文区

```
                    ┌── 微信事件？→ contentHint + 原文链接按钮
                    │
事件正文展示 ──→ 判断 ──┤
                    │                ┌── contentCn（翻译后的中文正文）
                    └── 非微信事件？→ 默认显示 ──┤
                                     │
                                     └── [查看原文] 按钮 → contentOriginal（英文）
```

| 条件 | 默认显示 | 附加操作 | contentHint |
|------|----------|----------|-------------|
| 微信事件 | 不显示正文 | 原文链接按钮 | "受平台限制，请点击查看原文" |
| 非微信、中文 | `contentCn` (=原文) | 无 | null |
| 非微信、非中文 | `contentCn` (翻译) | [查看原文] 按钮 | null |

### 2.4 详情页

| 字段 | 显示 |
|------|------|
| 标题 | `titleCn` |
| 信源 | `sourceName` + `sourceLevel` 标签 |
| 发布时间 | `publishedAt` |
| AI 摘要 | `summaryCn` |
| AI 推荐理由 | `aiReason` |
| 五维评分 | `scores` 雷达图/柱状图 |
| 正文 | 按 2.3 逻辑 |
| 原文链接 | `url`（外链） |

---

## 三、搜索逻辑

FTS5 全文检索字段：
- `titleCn` — 中文标题
- `summaryCn` — 中文摘要
- `contentCn` — 中文正文

默认不搜 `contentOriginal`（英文原文），用户研究需要时可高级搜索。

---

## 四、特殊字段说明

| 字段 | 微信事件值 | 非中文事件值 | 中文事件值 |
|------|-----------|-------------|-----------|
| `titleOriginal` | 中文标题 | 英文/日文原标题 | 中文标题 |
| `titleCn` | =titleOriginal | AI 翻译 | =titleOriginal |
| `contentOriginal` | **null** | 英文全文 | 中文全文 |
| `contentCn` | **null** | AI 翻译中文 | =contentOriginal |
| `contentHint` | "请点击原文链接" | null | null |
