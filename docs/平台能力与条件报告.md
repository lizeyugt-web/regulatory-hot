## 四、当前局限与下一步

### 局限

1. **信源覆盖有限**: 仅 FDA (美国) 和微信公众号 (中国)，EMA/NMPA/PMDA/WHO 等尚未接入
2. **依赖本地机器**: 守护进程需要 Windows 保持开机运行
3. **ECS watcher DB 写入**: 两个进程同时写 DB 可能导致冲突
4. **无事件聚类**: 多源报道同一事件无法自动合并
5. **无自动日报**: 不生成摘要报告

### 建议优先处理

| 优先级 | 事项 | 预计工作量 |
|--------|------|-----------|
| P0 | 移除 ECS watcher 的 DB 写入（避免冲突） | 5 分钟 |
| P0 | 本地启动 PM2 守护进程 | 1 分钟 |
| P1 | 接入 EMA (欧洲) + NMPA (中国) 信源 | 2-3 天 |
| P1 | 事件聚类（同事件多源折叠） | 1-2 天 |
| P2 | Vercel 部署前端 | 1 天 |
| P2 | 自动日报生成 | 1 天 |

## 五、快速操作指南

### 启动全自动采集

```bash
# 方式1: Windows 桌面双击
start_local.cmd → 输入 1 → 回车

# 方式2: PM2 命令行
pm2 start ecosystem.local.config.cjs
pm2 save

# 方式3: 直接运行
node scripts/local_daemon.cjs
```

### 手动操作

```bash
# 单次全流程
node scripts/local_daemon.cjs --once

# 仅 FDA 采集 + AI
node scripts/local_daemon.cjs --fda-only

# 仅 AI 分析
node scripts/local_daemon.cjs --ai-only

# 查看日志
pm2 logs local-daemon
# 或
type logs\local-daemon.log
```

### 启动前端预览

```bash
cd regulatory-hot
npx next dev -p 3457 -H 0.0.0.0
# 访问 http://localhost:3457
```
